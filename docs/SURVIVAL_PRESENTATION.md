# 사운드·튜토리얼·UI·감정 연출 개선

## 변경 파일

- `index.html`: 공통 사운드 정책·환경음 스케줄러, 첫날 안내, SVG 테두리, 꽃 장식과 감정/칭찬 로직.
- `tools/check_survival_presentation.py`: PC·모바일 브라우저 통합 회귀 검사. 테스트용 시간/상태 제어는 응답에만 주입되며 게임에 저장되지 않는다.
- 이 문서: 구현 범위, 검증 방법과 제한.

## 구현 및 재사용

| 항목 | 구현 |
|---|---|
| 발자국 계열 | 이동에서 발생하던 `step`과 인벤토리의 모래 같은 `inventory` 효과를 중앙 `play()` 정책으로 차단한다. 강제 재생 경로도 차단하며 원본 WAV와 생성 코드는 보존한다. 순수 UI 클릭음, 물·모닥불·벌·비·숲과 행동 고유 음원은 유지한다. |
| 새·부엉이 | 하나의 실제 시간 스케줄러에서 재생 **완료 후** 무작위 15–35초를 기다린다. 중복·주야간 교차 중첩을 방지하고 부엉이의 20:00–04:00 조건 및 기존 믹스 볼륨을 유지한다. 이전 2–5초/5–11초 주기보다 충분히 낮은 빈도다. |
| 첫날 강조 | 기존 저녁 안내와 야외 야간 경고 조건을 재사용한다. 문구는 기획서의 텍스트로 맞추고 글자색·위치·폰트 크기는 유지한다. 안내 글자 투명도, 경고 배경색, 화살표 투명도는 한 부모 요소의 1.2초 `ease-in-out` CSS 애니메이션을 공유한다. 경고 글자는 흰색으로 고정한다. |
| 동굴 방향 | 각 캐릭터의 시작 동굴 레지스트리를 사용한다. 첫날 20:00–06:00, 동굴에서 10m 초과일 때 표시한다. 도착하면 숨기고 다시 멀어지면 재표시한다. 카메라의 지면 기준 오른쪽/위쪽 벡터에 동굴 방향을 투영한다. 경로 찾기는 변경하지 않는다. |
| 회전 테두리 | 기존 캐릭터 버튼과 SVG를 재사용한다. 버튼의 실제 픽셀 크기·라운딩·border 폭을 측정하여 외곽에 맞춘다. 5px `#9CE9C0`, 내부 `#468B70`, 흰 글자, 시계방향 3초. 자동 모드에서만 표시한다. |
| 히나 꽃 | 2일차부터 자동 모드에서 안전하고 꽃 군집에 접근한 경우에만 진입당 18% 확률을 검사한다. 같은 군집에 머무는 동안 매 프레임 재추첨하지 않는다. 기존 꽃잎의 형상·재질을 재사용한 메시 하나를 머리에 붙이고 기존 어깨/팔꿈치 리그에 1.8초 모션을 덧씌운다. 이동 경로와 자원은 건드리지 않는다. |
| 꽃 유지·칭찬 | 착용 시점부터 정확히 `DAY_SECONDS`인 게임 내 24시간 유지한다. 수동 전환·수면은 장식을 제거하지 않는다. 친구별 세대당 1회, 5m 이내, 공통 직렬 큐로 칭찬→히나 답변을 처리한다. 기존 3초 말풍선/우선순위를 사용하고 긴급 상황·기존 대화·거래 동작에는 양보한다. |
| 초반 감정 | 5명 대사 데이터와 공통 선택 로직을 분리했다. 날짜·밤·고립 여부·합류 이력·의지력·안전 거점·실제 시간 쿨다운을 사용하고 동일 대사의 연속 반복을 막는다. 1–2일차에는 걱정·공포·그리움을 강조하며, 3일차 이후도 낮은 의지력에서는 불안을 유지한다. 자동·수동 모두 적용한다. |

## 검증

별도 터미널에서 저장소 루트의 정적 서버를 시작한 뒤 실행한다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
python3 tools/check_survival_presentation.py
```

검사는 Python Playwright와 `/usr/bin/chromium`이 필요하다. 네이티브 음원 재생, 차단 정책, 주야간 경계, 재생 완료 기준 간격, 동굴 안내의 거리/카메라 조건, SVG의 실제 위치/색/두께/주기, 꽃의 모드·위험·수명·중복·칭찬 조건, 감정 데이터와 실제 말풍선 발행을 검사한다. 꽃의 추가 draw call/삼각형 수도 동일 장면의 전후 렌더로 비교한다.

## 제한 및 성능

- 현재 실제 생존 캐릭터는 히나·다은 두 명이다. 서연·지유·민아를 새로 스폰하지 않는다. 세 명의 대사 데이터와 공통 처리 경로를 준비했으며, 검사는 테스트에만 등록한 캐릭터로 확장 경로를 확인한다.
- 꽃 상태는 현재 게임 세션의 게임 시간 기준이다. 기존 저장/복원 정책은 변경하지 않는다.
- 생존 수치, 이동/길 찾기, 제작/식사 자원 거래, 월드 그래픽과 기존 음원은 변경하지 않는다.
- 화살표와 테두리는 DOM/SVG이며 WebGL draw call을 추가하지 않는다. 꽃은 기존 GPU 형상·재질을 공유하고 착용 시 메시 하나만 추가한다. PC·모바일 조건에서 추가 비용은 draw call 1회, 삼각형 140개로 측정됐다. 군집 접근 검사는 4초 간격, 감정·칭찬은 0.5초 간격으로 처리한다.
- 브라우저의 모바일 조건 검증은 실제 휴대폰의 청감이나 장시간 성능을 보장하지 않는다.
