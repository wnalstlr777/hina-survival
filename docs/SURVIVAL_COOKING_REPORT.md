# 생존·불멍·요리·환경 수정

기준 커밋: `266f858`. 메뉴 버튼과 나무 에셋은 수정하지 않았다.

## 생존 상태

HUD의 체력은 `stats.energy`이다. 별도 HP 사망/게임오버 시스템을 새로 만들지 않고 다은의 기존 탈진·회복 규칙을 공통으로 사용한다.

- 히나의 체력 감소 하한 5를 제거했다. 체력 0에서 이동, 채집, 제작, 음식 애니메이션, AI 이동을 중단한다.
- 탈진 중에는 기존 휴식 회복식과 회복 품질 0.55를 사용하며, 기존 재개 체력 8에 도달해야 행동을 재개한다. 허기·갈증에 따른 회복 효율도 기존 식을 따른다.
- 기존 다은의 허기 0 체력 소모 **게임 시간 초당 0.10**을 공통 처리한다. 이동에만 걸려 있던 제한과 중복 차감을 제거했다. 탈진 중에는 기존 회복 처리를 우선하여 영구적인 회복 불능 루프를 방지한다.
- 히나 허기 0의 음식 확보를 휴식·선택 활동보다 먼저 판단한다. 원래 허기 감소 속도와 음식 회복량은 유지한다.
- 의지력 0 이동은 기존 0.12 배율을 유지하며, 복합 저속의 최소 이동과 보행 속도 동기화를 적용했다. 체력 0/탈진 판정이 우선한다.

## 모닥불·불멍

- 두 모닥불의 원본 원뿔 지오메트리와 불꽃 배치를 최종 1.6배로 설정했다. 장작, 모닥불 위치, 조명 거리/강도와 그림자 옵션은 유지한다.
- 기존 상승 불씨는 유지한다.
- 히나·다은의 불멍에만 바닥 L자 자세를 적용한다. 엉덩이 높이는 실제 지형을 기준으로 계산하고, 기존 고관절·무릎·팔꿈치를 재사용한다. 렌더링 오프셋은 다음 시뮬레이션 전에 복원한다.
- 일반 앉기·수면·이동 자세 및 불멍 보상/시간은 유지한다.

## 음식·요리

- 열매는 기존 **2초**, 구운 물고기와 새 요리는 **6초**이다.
- 양손과 물고기 소품, 기존 원형 게이지를 사용한다. 입에 가져간 후 씹는 구간에서만 `fish-chew.wav`를 반복 재생하고, 중단/완료 시 정지한다.
- 완료 시 1개 소비, 중단 시 아이템 보존. 기존 공통 회복식인 허기 최대 100 및 실제 허기 회복량의 10% 체력 회복을 유지한다. 열매의 기존 개별 회복량은 바꾸지 않았다.
- `요리` 카테고리의 샘플: **야자잎에 익힌 물고기**. 생물고기 1개 + 야자잎 1개 → 별도 `leafFish` 1개. 켜진 모닥불 4m 안에서 기존 제작 UI로 8초 동안 제작한다.
- 첫 샘플에는 선행 요리 숙련도 제한이 없다. 기존 분야 숙련도 처리와 완료 실패 시 재료 소비/중단 시 보존 규칙을 재사용한다. 완성 요리는 일반 구운 물고기와 같은 회복량이며 중복 제작할 수 있다.
- 인벤토리, 음식 등록/먹기, 드롭, 저장 자료에 새 아이템을 연결했다. 히나 생물고기 재료 수량에 구운 물고기가 섞여 계산되지 않도록 분리했다.

## 포획 사운드

히나 자동·수동의 실제 물고기 획득과 다은 자동·수동의 실제 성공 분기에서 하나의 `notifyFishCapture`를 사용한다. 동일 거래 객체는 한 번만 처리하고, 성공 소리는 재생 슬롯/일반 효과음 쿨다운으로 누락되지 않도록 우선 처리한다. 실패·관찰·재고 이동에는 포획 성공음을 호출하지 않는다. 기존 볼륨·음소거 설정을 유지한다.

다은 AI에는 숙련도 100 이후 실제 포획 시작 경로가 없었다. 기존 포획 처리와 일일 제한 4회, 성공 확률 0.48, 원래 숙련도 증가량을 재사용해 연결했다. 새 포획 수치나 별도의 AI 구조를 추가하지 않았다.

## 환경

구름 메시와 구름 그림자 생성/업데이트를 제거했다. 다른 환경의 시드 배치를 유지하며 비·천둥·낮밤·하늘 색상은 유지한다.

해안의 모래 타일 및 인접 해안 경계를 꽃 생성/재배치에서 제외한다. 기존 **15개 군집 풀 / 255송이 용량**과 내륙 군집 밀도, 벌·나비 비행/산개 로직은 유지한다. 해안에 해당하는 꽃은 표시하지 않는다.

## 야자잎 침대 확인 결과

이미 `mat` 레시피가 있다: 야자잎 6개, 생활 숙련도 기준 15, 제작 12초. 제작 후 빈 바닥을 찾아 메시를 배치한다. 수면 중 2.3m 안의 침대를 점유하고 내구도를 소모하며, 기상 시 점유를 해제한다.

다만 이 제작 침대로 자동 이동하거나 별도의 수면 회복 보너스를 연결하는 기능은 없다. 기존 히나의 `leafBed` 회복 보정은 별도 구형 경로이다. 요청대로 이번에는 침대 기능을 중복 추가하거나 확장하지 않았다.

## 최소 검증

PC/모바일 Chromium 조건에서 섭취 시간·양손 자세·아이템 소비/취소·회복량, 요리 재료/완성품/반복 제작/중단/불 조건, 허기 0·의지력 0·체력 0의 우선순위를 확인했다. 두 캐릭터와 수동/자동의 실제 포획 성공 분기에서 HTMLAudio `playing` 이벤트를 확인했다. L자 자세는 수치와 화면을 함께 확인했다. 해안 쪽으로 꽃 풀을 재배치해도 해안 꽃이 표시되지 않는지 확인했다.

장시간 자동 생존이나 실제 휴대폰 청감·발열 검사는 진행하지 않았다.
