# HINA SURVIVAL v15.2 — 추억앨범 / 환경음 버그 수정

ZIP 압축을 풀고 `index.html`을 실행하세요. `memories/`와 OGG 파일을 같은 구조로 유지하세요.

## 수정 사항

1. **DAY 1 추억앨범**: 유효한 2인 생존 저장 데이터가 없는 새 게임에서 구버전 추억앨범 기록을 자동 병합하던 동작을 제거했습니다. 신규 시작 시 도착 추억만 열립니다. 기존 2인 생존 저장 데이터가 있으면 그 저장 시점의 추억을 그대로 복원합니다. 새 게임 버튼을 누르면 기존 진행을 덮어씁니다.
2. **새소리/부엉이 중첩**: 모든 포인터/키보드 입력에서 오디오 잠금 해제를 시도하더라도 새소리 재생 타이머를 리셋하지 않도록 수정했습니다. 빠른 연속 입력 중 AudioContext resume 호출도 하나로 합칩니다. 환경음 ON 시에도 즉시 새소리가 연타되지 않도록 최소 간격을 둡니다.
3. **빗소리**: 기존 단일 Audio 루프를 그대로 유지합니다.

## 검증

- `index.html`의 실행 JavaScript 블록 전체 `node --check` 통과
- 신규 게임의 레거시 추억 자동 병합 코드 제거 확인
- 새소리 타이머가 `unlockAmbient()`에서 초기화되지 않는지 확인
- 원본 v15.1의 게임 기능·리소스 유지

**주의:** 위 검증은 소스/구문 검사이며 실제 모바일 기기에서의 청각 테스트는 별도로 필요합니다. 이전에 저장된 2인 생존 게임을 자동으로 이어하면 DAY 1이 아닐 수 있습니다. DAY 1부터 시작하려면 게임 내 `새 게임`을 선택하세요.
